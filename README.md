# SoldNSU

A campus marketplace for NSU students, built with Flask and MySQL for **CSE311 / CSE311L (Database Management Systems)**.

The project is in [`CSE311L/`](CSE311L). See [`CSE311L/README.md`](CSE311L/README.md) for features, setup and deployment, and [`CSE311L/docs/database-design.md`](CSE311L/docs/database-design.md) for the ER diagram and database design.
